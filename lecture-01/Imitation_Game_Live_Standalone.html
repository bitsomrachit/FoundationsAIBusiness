The Imitation Game

The class is the judge. It types questions through the door and has to say which answer came from a person. Five minutes of questioning was Turing's benchmark.

The key stays in this browser tab and is never saved to the file or sent anywhere except Anthropic. It clears when you close the tab, so paste it again next time. A whole class of questioning costs a few rupees.

Volunteer mode

Pick a student, hand them the keyboard, and let them answer as themselves. Their typing is masked on screen so the class cannot read it as it goes in. The model answers the same question in character. Both slips appear together.

The empty room

Both slips come from the model. One is trying to pass, one is answering as itself. The class votes for the person. The reveal is that there was never one. Worth doing once, at the end, and not twice.

After the vote

The applet prints the instruction the model was given. That is the whole trick, and it fits on one screen. Read it out and ask the room which line did the most work.
