Step 4 of 5 · Core AI Workloads
Training vs. Inference
Model Training
Offline · Months of Compute
  • • Goal: Learn parameters & weights from huge datasets.
  • • Compute: Tens of thousands of GPUs tied together for months.
  • • Math: Forward pass + Backpropagation (updating weights).
Model Inference
Real-Time · Your Query Right Now
  • • Goal: Generate a response for a specific prompt.
  • • Compute: Milliseconds on pooled data center GPUs.
  • • Math: Forward pass only (weights are fixed).
Step 5 of 5 · Infrastructure Comparison
An AI Query vs. a Google Search
Google Search
Index Lookup
∼0.3 WhGoogle's own 2009 disclosure — the only figure it has published
  • • Hardware: CPU/TPU servers built for fast lookup
  • • Operation: Matches your query against a pre-built index
  • • Per query: One lookup, same answer path every time
VS
AI Query
Neural Generation
∼0.3–3+ WhOpenAI's 2025 figure, up to independent high-complexity estimates
  • • Hardware: GPU clusters running matrix multiplication
  • • Operation: Recomputes a forward pass through billions of parameters
  • • Per query: Repeated once for every single token generated
The widely repeated "10× more energy" claim traces to a 2023 estimate built on older hardware and longer assumed responses. More recent company-disclosed figures put a typical AI query much closer to a search — though neither company publishes full methodology, so real uncertainty remains. What's not in dispute: a search is one index lookup; an AI query is a fresh neural network computation, repeated per token — a fundamentally heavier piece of infrastructure to run, regardless of the exact multiplier.
